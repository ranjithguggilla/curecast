# Dataset

`concrete.csv` is I-Cheng Yeh's high-performance concrete study: 1,030 real
laboratory mixes, each with eight design inputs and the measured compressive
strength.

Columns (units in kilograms per cubic metre of concrete unless noted):

| column | meaning |
|--------|---------|
| cement | Portland cement content |
| slag | ground granulated blast-furnace slag |
| ash | fly ash |
| water | mixing water |
| superplastic | superplasticiser (water-reducing admixture) |
| coarseagg | coarse aggregate |
| fineagg | fine aggregate |
| age | curing age in days |
| strength | compressive strength in megapascals (target) |
